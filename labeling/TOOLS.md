# Labeling - tools

This resource set includes the possibility of having tools among the broader collection of resources: some entries are full annotation systems, while others are model libraries, helper scripts, or integrations that support labeling workflows.

## ✨ Auto-labeling

### 🌍 Public repositories

#### 🔧 Backend-only automation

* [autodistill/autodistill](https://github.com/autodistill/autodistill) — Locally annotate from a foundation model and train a specialized model on top of it.
* [ultralytics/ultralytics](https://docs.ultralytics.com/models/sam-2/#sam-2-comparison-vs-yolo) — Auto-annotate using Segment Anything Model (SAM) with YOLO detections.
* [Nvidia Tao Auto Label](https://docs.nvidia.com/tao/tao-toolkit/text/data_services/auto-label.html) — GroundingDINO-based image annotation, usable locally or in the cloud.
* [yasho191/SwiftAnnotate](https://github.com/yasho191/SwiftAnnotate) — Multimodal annotation generation using leading LLMs and VLMs.
* [AlvaroCavalcante/auto_annotate](https://github.com/AlvaroCavalcante/auto_annotate) — Local annotation from pretrained object detection models using a configurable threshold.
* [mailcorahul/auto_labeler](https://github.com/mailcorahul/auto_labeler) — CLI workflow to generate annotations with multiple foundation models on local data.
* [akuonj/omanAI](https://github.com/akuonj/omanAI) — YOLOv8-driven bounding box generation for images.
* [fexploit/ComfyUI-AutoLabel](https://github.com/fexploit/ComfyUI-AutoLabel) — Image-to-text description generation.
* [Antraxmin/AutoLabeler](https://github.com/Antraxmin/AutoLabeler) — Ultralytics-powered image annotation automation.
* [pollyjuice74/CVAT-Auto-Labeler](https://github.com/pollyjuice74/CVAT-Auto-Labeler) — Automatic annotations for CVAT-backed image data.
* [Daniele-Cannella/auto_labeling](https://github.com/Daniele-Cannella/auto_labeling) — Phi-3 + grounding workflow for image auto-labeling.
* [jamesnatulan/auto-image-labeler](https://github.com/jamesnatulan/auto-image-labeler) — Zero-shot annotation using foundation models.
* [Ziad-Algrafi/ODLabel](https://github.com/Ziad-Algrafi/ODLabel/tree/main?tab=readme-ov-file) — Yolo-World-based labeling for new image batches.
* [sah4jpatel/AutoLabeller](https://github.com/sah4jpatel/AutoLabeller) — Another Yolo-World workflow for rapid image labeling.
* [aiXander/CLIP_assisted_data_labeling](https://github.com/aiXander/CLIP_assisted_data_labeling) — Few-shot CLIP embedding driven labeling.
* [ChunmingHe/WS-SAM](https://github.com/ChunmingHe/WS-SAM) — SAM-based full segmentation from weak medical-image annotations.
* [StriveZs/ALPS](https://github.com/StriveZs/ALPS) — Remote sensing annotation generation with SAM.
* [Fudan-ProjectTitan/OpenAnnotate3D](https://github.com/Fudan-ProjectTitan/OpenAnnotate3D) — Open-vocabulary auto-labeling for multimodal 3D data.

#### 🖼️ Annotation tools with human-in-the-loop

* [CVAT Automatic Labeling](https://github.com/cvat-ai/cvat?tab=readme-ov-file#deep-learning-serverless-functions-for-automatic-labeling) — General-purpose computer vision annotation platform with ML-assisted labeling.
* [Label Studio Auto Annotation](https://labelstud.io/guide/labeling#Perform-ML-assisted-labeling-with-interactive-preannotations) — Interactive data labeling with model-assisted pre-annotations.
* [Anylabeling](https://github.com/vietanhdev/anylabeling) — General-purpose computer vision annotation UI.
* [fabrylab/clickpoints](https://github.com/fabrylab/clickpoints) — Annotation tooling for image-based workflows.
* [halleewong/ScribblePrompt](https://github.com/halleewong/ScribblePrompt) — Medical image annotation guided by click prompts and segmentation assistance.
* [filonenkoa/autoannotator](https://github.com/filonenkoa/autoannotator) — Human-face annotation workflow with automatic support.
* [Babyhamsta/Yoable](https://github.com/Babyhamsta/Yoable) — YOLOv8-based UI for automatic labeling.
* [FennelFetish/qapyq](https://github.com/FennelFetish/qapyq) — Captioning + bounding-box generation with vision-language models and YOLO.
* [anujgaut/All-in-One-Label](https://github.com/anujgaut/All-in-One-Label/tree/main) — UI for running YOLO or Mask R-CNN on image data.
* [Ashish-Yallapragada/AI_AssistedImageSegmentation](https://github.com/Ashish-Yallapragada/AI_AssistedImageSegmentation) — Annotation support for zebrafish image analysis.
* [ParthShethSK/LabelPal](https://github.com/ParthShethSK/LabelPal) — TensorFlow model-assisted annotation for object detection workloads.
* [ksugar/qupath-extension-sam](https://github.com/ksugar/qupath-extension-sam?tab=readme-ov-file) — SAM-enabled medical imaging labeling in QuPath.
* [Neural-Symbolic-Image-Labeling/HEPHA](https://github.com/Neural-Symbolic-Image-Labeling/HEPHA) — Active-learning interface built around existing image-level annotations.

# Model design - Bibliography


## No embedding
[The Chicken and Egg Dilemma: Co-optimizing Data and Model Configurations for LLMs](https://arxiv.org/abs/2602.08351): use scaling laws applied after a few step training to select the best configuration.
[All models are wrong, some are useful: Model Selection with Limited Labels](https://arxiv.org/abs/2410.13609): use less data to find the best model and training config before training on the full data
[Large Language Model Selection with Limited Annotations](https://arxiv.org/abs/2605.24981): select best LLM from restricted data selected from a reference model output

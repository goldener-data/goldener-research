# Training strategy - tools

This resource set gathers tools, libraries, and frameworks that support training-strategy workflows, especially active learning and related sample-selection methods.

## 🌍 Public repositories

### Active learning

* [Alipy](https://github.com/NUAA-AL/ALiPy) — Active learning framework to evaluate, compare, and analyze active learning methods.
* [Baal](https://github.com/baal-org/baal) — Bayesian active learning library for PyTorch.
* [scikit-activeml](https://github.com/scikit-activeml/scikit-activeml) — Active learning library compatible with scikit-learn.
* [pyrelational](https://github.com/RelationRx/pyrelational) — Toolkit for building active learning strategies and related infrastructure.
* [Energizer](https://github.com/pietrolesci/energizer) — PyTorch/PyTorch-Lightning active learning framework.
* [Small-Text](https://github.com/webis-de/small-text) — Active learning toolkit for text classification tasks.

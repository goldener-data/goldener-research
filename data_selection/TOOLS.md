# Data selection - tools

This resource set includes the possibility of having tools among the broader collection of resources: some entries are full frameworks, while others are model-selection helpers, strategy libraries, or platform integrations for smart sampling and splitting.

## 🌍 Public repositories

### 🌐 General-purpose libraries

* [Adaptive](https://github.com/python-adaptive/adaptive) — Python library for adaptive sampling.
* [Coreax](https://github.com/gchq/coreax) — JAX coreset algorithms with fast execution and GPU support.
* [Scikit-Learn StratifiedKFold](https://scikit-learn.org/stable/modules/generated/sklearn.model_selection.StratifiedKFold.html) — Baseline stratified splitting strategy for controlled train/validation/test setup.

### 🧩 Embedding based selection

* [Voxel51 ZCore](https://github.com/voxel51/zcore) — Implementation linked to zero-shot coreset selection for unlabeled image data.
* [BRIEF](https://github.com/HR10108/BRIEF) — Bi-level optimization framework for coreset selection in LLM instruction tuning.
* [DSIR](https://github.com/p-lambda/dsir) — Data selection for text via importance resampling.
* [Astartes](https://github.com/JacksonBurns/astartes) — Better dataset split strategies for general machine learning workflows.
* [FAIR SSL Data Curation](https://github.com/facebookresearch/ssl-data-curation) — Clustering-based data curation for self-supervised learning.

## 🏢 Private tools

* [DataHeroes](https://dataheroes.ai/) — Data sampling techniques and automated processes for iteratively sampling, refining, and optimizing training datasets.

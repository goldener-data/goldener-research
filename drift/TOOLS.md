# Drift - tools

## 🌍 Public repositories

* [SeldonIO/alibi-detect](https://github.com/SeldonIO/alibi-detect) — General-purpose drift and explainability library for tabular, image, text, and time-series data.
* [torchdrift/torchdrift](https://github.com/torchdrift/torchdrift) — PyTorch-first library for drift detection in deep-learning feature spaces and image pipelines.
* [NannyML/nannyml](https://github.com/NannyML/nannyml) — Monitoring and drift detection toolkit focused on production ML validation and degradation tracking.
* [evidentlyai/evidently](https://github.com/evidentlyai/evidently) — Open-source monitoring framework with drift detection, dataset checks, and reports.
* [deepchecks/deepchecks](https://github.com/deepchecks/deepchecks) — ML validation library with drift, data quality, and model integrity checks.
* [online-ml/river](https://github.com/online-ml/river) — Streaming ML library with online drift detection and adaptive learning workflows.

## 🏢  Private platforms

* [Evidently AI](https://www.evidentlyai.com/) — Practical drift monitoring and data quality dashboards for ML systems.
* [NannyML](https://www.nannyml.com/) — Data drift and model performance monitoring for deployed ML systems.
